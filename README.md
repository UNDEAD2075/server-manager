# Server Manager (Qt Terminal GUI)

Легковесный графический менеджер серверов и фоновых служб на Python (PyQt6 + TTY/pyte) для Arch Linux. Разработан для удобного параллельного запуска локальных LLM-инференсов (`llama-server`, `FastFlowLM`), WebUI-интерфейсов, парсеров, прокси и произвольных CLI-утилит.

---

## Возможности

- **Полноценный встроенный терминал**: реальный псевдотерминал (`pty`), корректная обработка ANSI-цветов, кольцевой буфер истории на 5000 строк.
- **Многострочные переносимые вкладки**: адаптивный перенос ярлыков на несколько строк при заполнении ширины окна. Вкладки можно перетаскивать (Drag-and-Drop).
- **Управление вкладками**: закрытие по клику СКМ (средняя кнопка мыши) или через ПКМ -> *Закрыть вкладку*.
- **Индикация статуса**: на ярлыке каждой вкладки отображается индикатор состояния (зеленый — работает, красный — остановлен).
- **Горячие кнопки панели меню**:
  - `▶ Старт` — запуск текущей вкладки.
  - `⏹ Стоп` — плавный останов процесса (`SIGTERM` -> `SIGKILL` по таймауту).
  - `🔄 Перезапуск` — перезапуск службы.
  - `🧹 Очистить` — мгновенный сброс экранного буфера и истории терминала.
  - `⚙ Настройки` — конфигурация текущего сервера.
- **Гибкая настройка серверов**:
  - Имя вкладки.
  - Бинарник/команда и аргументы запуска.
  - Рабочая директория (`cwd`).
  - Переменные окружения (`KEY=VAL` построчно).
  - Выбор цвета фона терминала через палитру и кнопка сброса к `#0d1117`.
  - Затемнённая фоновая картинка для терминала с кнопкой очистки.
- **Система профилей**: меню *Профили* позволяет сохранять текущие наборы настроенных вкладок в JSON, загружать их в один клик и закрывать все вкладки разом.
- **Системный трей и завершение работы**:
  - Всплывающий статус списка активных серверов при наведении на значок в трее KDE/GNOME.
  - Выбор действия для кнопки `[X]`: закрыть, свернуть на панель или спрятать в трей.
  - Плавное завершение (Graceful Shutdown) всех фоновых процессов при выходе.

## Требования

- Arch Linux (или любой дистрибутив Linux).
- Python 3.12.
- Системные библиотеки Qt6.

---

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/username/server-manager.git
   cd server-manager
   
2. Выдайте права на исполнение и запустите скрипт установки:
  chmod +x install.sh
  ./install.sh
  
3. Запуск:
  ./run.sh
  или
  source .venv/bin/activate
  python main.py

---

## Профили и файлы конфигурации

Все пользовательские параметры, активные сервера и сохраненные профили хранятся локально в домашней директории пользователя:

    - Основной конфиг текущего состояния: ~/.config/server_manager_clean.json
      (содержит параметры геометрии, последней открытой сессии, режим закрытия окна и активный список серверов)

    - Сохраненные профили: ~/.config/server_manager_clean_profiles/<имя_профиля>.json
      (файлы профилей, созданные через меню «Профили -> Сохранить профиль»)
